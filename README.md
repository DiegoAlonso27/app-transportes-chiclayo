# App Transportes Chiclayo — Prototipo

Prototipo navegable de la app de venta de pasajes de Transportes Chiclayo, hecho con React (vía CDN, sin build) y Babel standalone. Corre 100% en el navegador, por lo que se puede publicar directo en GitHub Pages.

## Ver el prototipo

Una vez publicado con GitHub Pages, el link va a ser:

```
https://<tu-usuario>.github.io/<nombre-del-repo>/
```

`index.html` carga el flujo completo de la app dentro de un marco de celular (login, home, resultados, asientos, datos de pasajeros, confirmación, etc.).

## Correr en local

No requiere instalación ni build. Basta con abrir `index.html` en el navegador, o servir la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
